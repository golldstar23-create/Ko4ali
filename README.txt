Ko4Ali — многостраничный магазин спортивной экипировки

Как запустить:
1. Распакуй архив.
2. Открой index.html в браузере.
3. Для разработки удобнее открыть папку в VS Code и запустить через расширение Live Server.

Страницы:
- index.html — главная
- catalog.html — каталог с поиском, категориями и сортировкой
- product.html — страница товара
- cart.html — корзина
- about.html — о бренде
- contacts.html — контакты и демо-форма

Технологии: HTML5, CSS3, Vanilla JavaScript. Корзина сохраняется в localStorage.
Важно: оформление заказа и форма контактов демонстрационные — для реальной работы нужен backend/платёжный сервис. Изображения и Google Fonts загружаются из интернета.
